# 3단계: 화면 연결 및 검증

당시 Maven/POM 명령은 역사 기록입니다. 현재 실행·보고서 경로는 [Gradle 빌드](GRADLE_BUILD.md)를 따릅니다.

2026-10-14 후속 작업에서 당시의 실행 제한을 해소하고 실제 DB·타입 검사·브라우저 검증을 완료했습니다. 현재 상태는 [후속 검증 보고서](STAGE4_REPORT.md)를 참고합니다. 아래는 3단계 당시 기록입니다.

기준일: 2026-10-13. 작업은 기존 Auknowlog가 아닌 독립 과제의 임시 체크아웃에서 수행했습니다. 이 단계의 변경은 GitHub에 커밋·푸시하지 않았습니다.

## 구현

- 건수 카드, 왼쪽 지연 로딩 계층, 가운데 전체 Pod·부모별 목록, 오른쪽 상세·경로.
- 이름 검색·유형·상태 필터, 250ms 디바운스, 오래된 요청 취소·응답 차단.
- 검색 리소스의 전체 경로 표시, 조상 이동 및 트리 위치 펼침·스크롤 이동.
- 고정 높이 가상화, 최대 5페이지·500개 목록 캐시, 계층 24페이지 캐시.
- 현재 조회 창·펼친 부모·선택 상세의 수동 갱신, 오류·빈 상태·재시도.
- 테스트 전용 응답을 실제 사용 코드와 분리. AI 호출·비용·외부 공개 서버 생성 없음.

API·DB 변경은 없으며 [기존 계약](API.md)에 연결했습니다. 설계 이유와 UX 제한은 [화면 렌더링 설계](FRONTEND_RENDERING.md)에 기록했습니다.

## 실행한 검증

캐시된 공개 도구를 사용했습니다. Vue 3.5.20, Vite 7.3.6, Vitest 3.2.7, Vue Test Utils 2.4.6, jsdom 26.1.0, Node 22.23.2 환경입니다. 프로젝트의 node_modules는 기존 설치 패키지에 대한 임시 심볼릭 링크이고 Git에서 제외됩니다. 기존 프로젝트 소스나 설정은 변경하지 않았습니다.

| 검증 | 개수·결과 | 범위 |
|---|---|---|
| API 클라이언트 | 7개 통과 | URL·부모·상태·커서·검색·Unicode·취소·오류 매핑 |
| 커서 이동 창 | 7개 통과 | 500행 상한, 중복 요청 방지, 오래된 응답, 갱신·실패·재시도 |
| 가상화 | 4개 통과 | 10만 숫자 항목의 DOM 상한, 빈 범위·끝 범위·이동·캐시 제거 보정 |
| 전체 화면 | 11개 통과 | 초기 API, 펼침, 상세·속성·경로, 부모 탐색, 검색·필터, 선택·갱신·오류, HTML 텍스트 출력 |
| 계층 | 4개 통과 | 형제 페이지 교체·이전, 페이지 밖 목표 고정, 캐시 제거, 갱신·루트 복귀 |
| 합계 | 33개 통과 | Vitest·jsdom, 실제 DB와 브라우저 E2E 아님 |
| Vite 프로덕션 번들 | 통과 | Vue·TypeScript 문법 변환 및 번들, 타입 검사와 별도 |

실행 명령:

```bash
cd frontend
npm test
# 캐시 도구를 이용한 vite build 실행; 정식 npm run build는 타입 검사도 필요
```

## 실행하지 못한 검증

- `npm run typecheck`: 캐시에 vue-tsc·TypeScript가 없어 `vue-tsc: command not found`. 정식 `npm run build` 전체 통과라고 보고하지 않습니다.
- 실제 Vite 서버: 127.0.0.1:5174 바인딩 시 `listen EPERM`. 정상 기동·브라우저 화면 캡처·실제 API E2E를 하지 못했습니다.
- PostgreSQL 및 Testcontainers: 앞 단계에서 확인한 Docker·공유 메모리 제한으로 여전히 미검증입니다.
- Chrome CPU 4x·캐시 OFF 초기 500ms, 펼침 100ms, 검색 300ms, 필터 200ms, 55FPS, 갱신 200ms, 메모리 목표는 측정하지 않았습니다. 테스트 소요 시간과 번들 크기는 이 목표 달성 근거가 아닙니다.
