# 권한이 필요한 확인과 현재 진행 범위

기록일: 2026-10-16

## 현재 확인 상태

| 확인 | 필요한 접근 | 이번 상태 | 대체하면 안 되는 것 |
|---|---|---|---|
| Chrome 작업관리자의 해당 탭 메모리 | 컴퓨터 사용 도구의 macOS 손쉬운 사용(Accessibility)·화면 기록(Screen Recording), 접근 가능한 데스크톱 | 승인 후 네이티브 Chrome 정보 조회·화면 캡처 성공. 실제 탭 메모리 측정 자체는 미실행 | JS heap·renderer RSS를 탭 메모리로 기록하지 않음 |
| Chrome Performance/FPS 미터의 수동 스크롤 확인 | 위 네이티브 UI 접근과 Chrome 개발자도구 | 접근 권한은 확인, 직접 관측 미완료 | CDP 합성 프레임률만으로 원문의 FPS 미터 검증 완료라 하지 않음 |
| 최종 Jenkins 전체 검증 | 공개 이미지용 임시 클라이언트 설정·기존 로컬 Docker 엔진 | 빌드 15 SUCCESS. 이미지·브라우저·실제 인증·복구·정리까지 완료, 사용자 키체인 승인이 CI 선행 조건이 아님 | CI 해결을 개인 Docker 도우미 자체 수리나 수동 성능 검증 완료로 확대하지 않음 |

**현재 CI는 사용자 Mac 직접 조작 없이 완료했습니다.** 공개 이미지 조회를 개인 자격증명 도우미와 분리하고 macOS Testcontainers의 VM socket을 맞춰 Jenkins 빌드 15 전체 성공·정리를 확인했습니다. 전역 설정/기존 컨테이너 18개를 보존했고 Docker 전체 재시작은 하지 않았습니다. [최신 실행 근거](verification/2026-10-16-public-image-ci.json), [설계·지원 범위](CI_REPRODUCIBILITY.md#공개-이미지와-개인-docker-설정-분리)를 참고합니다. 네이티브 권한 승인 뒤 조회/캡처는 성공했지만 후속 화면 확인 시 Mac 잠금이 확인됐으며 실제 메모리/FPS 측정은 별도입니다.

컴퓨터 사용 권한을 승인하려면 도구가 띄운 안내와 macOS 개인정보 보호 및 보안 설정에서 해당 앱의 손쉬운 사용·화면 기록 승인을 확인해야 합니다. 승인은 사용자가 직접 합니다. Mac 로그인 암호를 채팅으로 전달할 필요는 없습니다. 잠금 화면·보안 설정을 우회하거나 보호 기능을 끄지 않습니다.

개인 Docker 도우미 대기의 정확한 원인은 확정하지 않았습니다. 도우미 응답 대기만으로 "권한 미승인이 원인"이라고 단정하지 않으며, CI 완료를 위해 사용자가 키체인 창을 직접 확인할 필요는 없어졌습니다. 개인 레지스트리 로그인이 필요할 때는 별도 확인 대상입니다. 전역 Docker 자격 증명을 삭제하거나 키체인 보호를 끄지 않으며 Mac 비밀번호를 채팅으로 전달하지 않습니다.

이전 빌드 12는 `ABORTED`, cleanup 통과·CI 컨테이너 잔존 0으로 정리했습니다. 서버 107개(실제 PostgreSQL 44 포함)·프론트 77개·빠른 검사 39개는 통과했지만 당시 이미지·브라우저·인증·복구는 미완료였습니다. [당시 검증 근거](verification/2026-10-16-hardening.json)를 보존하며 이후 빌드 15 전체 검증과 구분합니다.

이전 후속 확인에서 사용자 승인 후 네이티브 조회·캡처와 독립 Docker 도우미가 응답했지만, 빌드 13 안에서는 도우미 대기가 재발했습니다. 빠른 검사 39·서버 107·프론트 77·타입/빌드·audit 0건 뒤 `ABORTED`·cleanup 통과·CI 컨테이너 0을 확인했습니다. [당시 재실행 근거](verification/2026-10-16-ci-retry.json)는 보존합니다. 이후 빌드 14의 Ryuk socket 실패를 수정하고 빌드 15에서 최종 전체 성공했습니다. 화면 권한 재승인·키체인 설정 변경을 반복하는 방식으로 해결하지 않았습니다.

사용자가 직접 측정해도 됩니다. 이때 사용 URL/실행 버전·Chrome 버전·CPU 4x·캐시 OFF 여부·데이터 규모·확인 시점·스크롤 전후 메모리를 함께 남겨 주세요. 메모리 300MB는 과제의 참고 목표이며, 넘으면 실제 원인과 개선 방향을 기록합니다. 현재 초과 여부를 추정하지 않습니다. 측정 방법은 [성능 기준](PERFORMANCE.md)을 따릅니다.

## 권한 없이 계속 가능한 검증

- 실제 PostgreSQL Testcontainers·Flyway·10만 데이터 API·조회/인증 테스트
- JVM/프론트 단위 테스트·타입/빌드·빠른 품질 게이트
- 격리 환경의 headless Chromium 화면/Keycloak E2E
- 실행 중인 로컬 Jenkins의 인증된 CI 실행·이미지 일치·격리 장애/복구·컨테이너 정리

위 검증은 네이티브 화면 접근과 별개입니다. 이번에 보완한 토큰 정책·DB 풀 고갈/복구는 자동 테스트로 검증하며 수동 권한을 이유로 생략하지 않습니다.

## 별도 요청/승인 후 수행할 작업 — 현재 필수 보완은 아님

- **원본 commit/push·제출 소스 배포:** 사용자 요청 전에는 수행하지 않습니다. 현재 검증용 임시 Git fixture 커밋과 원본 저장소 이력은 다릅니다.
- **Jenkins 원격 SCM/webhook:** 실제 저장소 주소·최소 권한 자격 증명·연결 방식을 정한 뒤 검증해야 합니다. GitHub Actions를 다시 추가하거나 원격 Jenkins를 임의 공개하지 않습니다.
- **클라우드·공개 HTTPS·유료 API·SMTP:** 이번 과제의 안정성 보완에 필요하지 않아 실행하지 않습니다. 비용/외부 노출이 있는 별도 목표로 결정해야 합니다.

필요한 검증을 마무리하는 것과 접근 권한 확대·새 기능 추가는 구분합니다. 현재 권한 대기만을 이유로 새로운 OSS나 대체 수치를 만들어 목표를 완료 처리하지 않습니다. [요구 대조와 보완 근거](REQUIREMENTS_AND_HARDENING_REVIEW.md), [작업 이력](WORK_HISTORY.md)에 실제 완료/미확인을 구분해 기록합니다.
