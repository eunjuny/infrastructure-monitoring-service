# 운영 콘솔 UI 개선

2026-10-18 운영 관측 하단에 ADMIN 전용 [관리자 경보 메일](ALERT_EMAIL.md)을 추가했습니다. 단일 수신 주소·발송 체크·저장/오류/미설정 안내를 표시하고, SMTP 미설정 중 발송은 비활성화합니다. 비밀 설정은 UI에 노출하지 않습니다. 실제 데스크톱/모바일 E2E와 체크박스 폭 회귀를 확인했습니다.

기준일: 2026-10-14. 기존 API·DB와 계층 모델을 유지하고 탐색·조회 화면을 개선했습니다. 새 UI 라이브러리나 유료 서비스를 추가하지 않았습니다.

후속 확장에서는 조회 범위 선택·상세 변경 이력·운영 관측을 실제 API와 함께 추가했습니다. 초기 레이아웃 개선과 달리 이 확장은 V3 이력 테이블과 Prometheus API도 포함합니다. 리소스 탐색과 운영 관측을 상단 메뉴로 구분하고, 지표는 서비스의 실제 수집값으로만 표시합니다. [최신 동작과 검증](OPERATIONS_AND_DELIVERY.md)을 참고합니다.

## 제출용 화면 정돈 — 2026-10-18

운영자가 조회·판단하는 정보와 개발/검증 설명을 분리했습니다. 새 API·데이터 생성·권한 변경 없이 기존 기능을 유지합니다.

- 탐색: 소개 문장·ID 정렬 방식·캐시 보관 수·조작 튜토리얼을 기본 화면에서 제거합니다. 목록의 경로가 없는 행에 내부 ID를 부제목으로 반복하지 않고, ID는 상세에서 확인합니다. 검색 결과의 실제 경로는 유지합니다.
- 범위/상태: 선택한 조건이 있을 때만 범위·검색어·상태와 초기화를 표시합니다. 상태 합계는 `조회된 N개 기준`이라고 표시해 전체 상태 집계로 오해하지 않게 합니다. 전체 집계가 아니라는 설명은 title에도 유지합니다.
- 관측: 실제 서비스 지표 7개와 P95 차트 2개를 먼저 표시하고 Mock 배치 지표 3개는 기본 접힌 `Mock 시뮬레이터 지표`에서 제공합니다. 조회/PromQL/수집 수·응답 계약은 그대로이며 접기는 추가 조회를 만들지 않습니다.
- 경보: 알려진 세 규칙을 넓은 화면에서는 나란히 배치하고 작은 화면에서는 세로로 표시합니다. 상태·임계 조건·대응 방법·시작 시각은 유지하고, 독립 알림 경로와 화면의 한계는 접힌 `알림 전달 안내`로 옮깁니다. API가 unavailable일 때의 오류 메시지는 숨기지 않습니다.
- 빈 데이터: 누락은 `표본 없음`으로 유지하고 단위를 붙이지 않습니다. 차트 표본이 부족하면 간단한 빈 상태를 보여주며 값이 0인 것 같은 축을 만들지 않습니다. 현재값 누락·소스 장애·실제 0은 계속 구분합니다.
- 이력: 반복되는 시뮬레이터 설명은 없애고 발생 시각·변경 전후 값·24시간/전체 20,000건 보관 기준을 유지합니다.

Mock 데이터를 실제 Kubernetes 측정값으로 오해시키지 않도록 상단 `MOCK DATA`와 하단 `Mock 데이터 · 읽기 전용`은 유지합니다. 서버·DB·JVM 지표는 실제 앱 계측값입니다. 기존 목록/트리/캐시 상한·요청 취소·폴링·지연 청크·서버 권한을 변경하지 않습니다.

검증: Vitest 86개·vue-tsc/Vite 빌드와 실제 Keycloak E2E 10개(기존 8개 + 1440px/390px 제출 화면 2개)를 확인했습니다. 기본 7개/접힌 3개 지표, 실제 수집 성공, 키보드 접기·펼치기, 모바일 가로 넘침 없음과 기존 15만/10만/5만 범위를 포함합니다. 새 전체 Jenkins·최종 Chrome Performance/탭 메모리 판정과 구분하며 실행 결과는 WH-036에 기록합니다.

추가 성능 확인은 15만 데이터/실제 인증/CPU4x/cache OFF에서 20회씩 두 묶음을 수행했습니다. 두 실행 모두 기능/측정 오류는 0이지만 일부 목표 초과로 exit 1입니다. 캡처 작업과 겹친 첫 실행을 보존하고 캡처/빌드 없이 다시 측정해도 첫 펼침 2/20·검색 1/20·읽기 전용 갱신 1/20이 목표를 초과했습니다. 두 번째 SSO 재진입 최대 480.81ms·callback 최대 371.8ms는 각각 500ms 이내입니다. UI 기능 검증과 전체 성능 합격을 구분하고 원인은 미확정입니다. [두 실행 수치·환경·한계](performance/2026-10-18-submission-ui.json)를 참고합니다.

초기 성능 개선에서는 정보·기능·색상·아이콘을 유지하고 상세/운영/이력 코드를 선택 시 로드하도록 분리했습니다. 날짜는 로컬 24시간 숫자 형식, 건수는 정수 쉼표 형식이며 기본 폰트는 Arial·Apple SD Gothic Neo·Malgun Gothic입니다. 외부 폰트나 새로운 UI OSS는 추가하지 않았습니다. 닫힌 조회 범위 옵션은 DOM을 만들지 않습니다. [동일 조건의 60회 측정·11개 실제 브라우저 회귀 검증](STARTUP_PERFORMANCE.md)을 참고합니다.

## 적용 범위와 이유

| 개선 | 적용 방식 | 목적 |
|---|---|---|
| 콘솔 공통 레이아웃 | 상단 문맥·자동 갱신, 좌측 탐색기, 중앙 목록, 우측 상세 | 조작 위치를 고정하고 목록 탐색 중 상세를 확인 |
| 유형별 바로가기 | Cluster·Node·Namespace·Pod 메뉴와 건수 카드 | 유형 이동 시 검색·부모·상태·커서를 초기화해 전역 조회 |
| 조회 범위 표시 | 선택 부모 이름·검색 범위 설명·초기화 버튼 | 부모 목록과 전역 검색의 차이를 명확하게 표시 |
| 열 중심 목록 | 이름·경로, 유형, 상태, 부모, 갱신 시각 | 이름만으로 비교하기 어려운 문맥을 함께 확인 |
| 상태 요약 | 보관 중인 창의 정상·주의·오류 수 | 조회창 상태를 빠르게 파악; 전체 DB 통계와 구분 |
| 상세 패널 | 닫기·개요/관계 탭·조상 이동·Node meter | 같은 화면에서 속성·위치 확인 |
| 키보드 | `/` 검색 포커스, `Escape` 상세 닫기, 상세 탭 좌우 이동 | 반복 탐색을 빠르게 수행하고 포커스 유지 |
| 모바일 | 유형 메뉴 유지, 계층은 기본 접힘·버튼으로 펼침, 상세 세로 배치 | 작은 화면에서 목록 우선 노출, 가로 넘침 방지 |

`계층에서 위치 보기`는 모바일에서도 계층을 펼치고 해당 경로로 이동합니다. 유형 메뉴나 건수 카드로 다른 유형을 선택하면 이전 상세를 닫고 새 조회로 이동합니다. 조건 초기화는 검색·상태·부모를 해제합니다.

## 데이터와 표시의 경계

2026-10-18 상세 개요에 진단을 추가합니다. Cluster 준비 Node/문제 Pod와 Namespace 전체/오류/미준비 Pod는 전체 하위 DB 집계이며 기존 목록 상태 요약과 다릅니다. Node 조건/용량·Pod phase/준비/사유/대표 이미지/워크로드와 Mock 출처·없음/0·단위·긴 문자열 줄바꿈을 제공합니다. 새 코드는 상세 선택 시 로드됩니다. [동작·정의](RESOURCE_DIAGNOSTICS.md)를 참고합니다.

- 상단 네 건수는 `/summary`의 실제 테이블별 수입니다.
- 상태 요약은 **현재 보관한 조회창 최대 500개**의 집계입니다. 화면에 `조회된 N개 기준`을 표시하고 title에 전체 상태 집계가 아님을 남깁니다. 새 DB 집계 API를 만들지 않았습니다.
- Node CPU·메모리 meter는 상세 API의 현재값입니다. 추이 차트·실측 Kubernetes 메트릭을 생성하지 않습니다.
- 목록 갱신 시각은 `updatedAt`입니다. 상세에는 전체 날짜·시간을 표시합니다. 좁은 목록에서는 일부 열을 숨기고 상세에서 확인합니다.
- UI에 `MOCK DATA`, 읽기 전용 안내를 표시합니다. 이 과제의 Cluster → Node → Namespace → Pod는 탐색 모델이며 실제 Kubernetes 관계와 같다는 뜻이 아닙니다.
- 로그·터미널·YAML 편집·배포·GPU·알림 등 미구현 메뉴를 추가하지 않았습니다. 활성처럼 보이는 가짜 기능을 두지 않습니다.

## 유지한 성능 전략

행 높이 60px·트리 44px, 최대 500개 목록 캐시·24개 계층 페이지 캐시, 제한된 GET·폴링·취소·백오프를 유지했습니다. SVG는 표시되는 행에만 렌더링합니다. 목록 컬럼을 늘렸다고 전체 10만 건을 로딩하거나 DOM에 표시하지 않습니다. CPU 4x·캐시 OFF의 실제 측정은 [성능 검증 보고서](PERFORMANCE_RESULTS.md)에 기록했습니다. 초기 레이아웃·날짜 표시의 불필요한 계산과 무한 요청 대기를 보강했습니다.
